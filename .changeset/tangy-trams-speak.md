Each compile's `meta.dependencies` is what it read beyond its template, on top of what its template and tag lookups read (shared, not copied), as an opaque handle: `taglib.forEachDependency(dependencies, visit, seen)` calls `visit` with each path to watch and its kind (`"file"`, `"missing"` or `"directory"`), skipping the layers already in `seen`, and `taglib.readDependencies(dependencies)` digests what it read as it is now (counting of a directory only that it is there and the entries looked for), equal in any process, and wherever it all moves, until some of it changes. `taglib.invalidate(paths, cache)`, given one path or several as one invalidation, marks stale what read a reported path (as `path.resolve` gives it, so relative and non-normalized paths match) and returns every template marked, whatever cache compiled it and whether or not its compile threw, dropping those `cache` holds, and `taglib.revalidate(cache)` does the same for every path changed on disk since it was read, which `@marko/compiler/register` runs once per tick; a compile cache hit reads nothing from disk. A tag lookup that fails to build (a malformed `marko.json`, a `tags-dir` or import not there yet) is kept until something it read or looked for changes, as one that built is, so the templates it failed are returned then too. `taglib.getDependencies(dirnames)` gives such a handle for what the tag lookups of some directories read with every tag loaded, these also from the Babel-free `@marko/compiler/taglib` entry. Translators record what a compile reads with `taglib.addFileDependency(filename)` and `taglib.addDirectoryDependency(dir, names)`, the latter returning the entries of `dir` that `names` name. Nothing read in `node_modules` is recorded, as what is installed is taken not to change while the process runs: after an install a caller calls `taglib.clearCaches()`, and pairs the digest, which covers the project's reads (a linked workspace package's files among them), with its own install signal such as a lockfile hash. `meta.watchFiles` stays empty, `meta.analyzedTags` is no longer set, and `TaglibLookup.watchFiles` is removed.
